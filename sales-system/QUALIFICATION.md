# Qualification — V3

## Les 7 questions

1. Quelle est votre activité et votre ville ?
2. Depuis combien de temps l'activité fonctionne-t-elle ?
3. Avez-vous déjà un site ? Si oui, lequel ?
4. Quel est l'objectif principal du site ?
5. Quels services souhaitez-vous présenter ?
6. Avez-vous déjà les textes/photos/logo nécessaires ?
7. Quand souhaitez-vous idéalement lancer le site ?

## Signaux positifs
- activité existante
- décideur présent dans la conversation
- objectif précis
- contenu disponible
- accepte un périmètre défini
- comprend la logique 50/50
- calendrier réaliste

## Signaux d'alerte
- "fais d'abord et je verrai"
- demande de travail complet gratuit
- veut copier exactement un autre site
- changements illimités
- compare uniquement les prix
- refuse l'acompte
- ne fournit aucune information après plusieurs demandes

## Règle de décision

A — HOT:
activité établie + besoin clair + budget compatible + délai raisonnable.
=> proposer une formule.

B — WARM:
besoin réel mais timing ou contenu pas prêt.
=> suivre plus tard.

C — COLD:
prix uniquement / activité incertaine / scope impossible.
=> ne pas poursuivre inutilement.
